# 10｜Phase 1 迭代路线图、Epic Backlog、交付与验收

版本 v0.1。计划按 **16 周 / 8 个双周 Sprint** 提供建议节奏；实际排期取决于工程师和教研审核人数，是规划估算而非交付承诺。优先级先 P0 质量门禁，后 P1 体验增强。

## 1. 人员配置假设

建议最小跨职能小队：产品/技术负责人 1、后端 2、前端 1～2、数据工程 1（可与后端兼任）、教研审核 1～2、测试 1（可兼职）、设计与 DevOps 按需共享。若仅 1～2 位工程师，需要按依赖串行开发并延后 P1 功能，不能简单照搬 16 周。

## 2. 阶段计划（交付门槛 Gate）

| 阶段 | 周期 | 关键交付 | Exit Gate |
|---|---|---|---|
| P1.0 基础标准 | W1–W2 | Contract v1、Source/Rights、ER、课程映射、发布版本、CI | 三问题样例通过 schema/版本测试；来源/权利模型冻结 |
| P1.1 内容生产 | W3–W5 | CMS 创建、Math 编辑预览、答案/rubric、双审核、不可变发布 | 教研录入 30 道样题并完成双审核 |
| P1.2 学生体验 | W6–W8 | 题库列表/筛选、详情、题单、账号、收藏 | 端到端完成“搜索→开题→练习入口” |
| P1.3 判题学习 | W9–W11 | 答案解析、数值/选项/表达式判题、提交、历史/错题 | 数学黄金样本+历史版本回归通过 |
| P1.4 多源接入 | W12–W14 | 批次导入、SourceAdapter、去重候选、权利、质量队列 | 两种独立来源格式演示 + 幂等重放 |
| P1.5 上线硬化 | W15–W16 | 异常/监控、安全审计、备份恢复、性能、操作手册 | 全部 P0 AC、权利拦截、恢复演练通过 |

注意：W1 就实现导入/来源的最小数据模型；P1.4 是产品化多源操作台而不是第一次考虑多来源。权利审查、权限校验、版本保留在所有 Sprint 贯穿。

## 3. Epic 与可交付 Story 拆分

### EPIC E01：内容身份与版本（P0，S1–S2）
- LM-101：实现 Problem、Revision、logical Part 与 revision Part 关系、唯一约束。AC：一题三问独立持久化，新版不改变旧的 revision_part_id。
- LM-102：内容契约 JSON Schema、fixture 校验 CLI。AC：正反例对照可自动通过/失败。
- LM-103：规范化 MathRichText 和 KaTeX 渲染安全管道。AC：输入恶意 HTML 不执行；数学公式可预览。
- LM-104：知识点系统/课程 release；种子上海高中分类（注明试点非官方树）。AC：一题跨多个课程发布版本可查询。
- LM-105：来源登记/授权 gate。AC：无授权公开发布被拒绝。

### EPIC E02：CMS 与发布（P0，S2–S3）
- LM-201：新增/编辑/复制修订、乐观锁。AC：并发冲突不覆盖。
- LM-202：多小问、答案类型、rubric、解析、媒体编辑器。AC：逐问权重保存并合计分数正确。
- LM-203：预检规则和错误定位。AC：缺答案/媒体/权利阻断送审。
- LM-204：数学+版权复核、审计、发布不可变快照。AC：作者不能自己终审；旧内容仍可复现。
- LM-205：应急撤稿/权利冻结。AC：列表/详情/下载均拒绝受限内容。

### EPIC E03：题库与学生端（P0，S3–S4）
- LM-301：公开题列表、过滤、稳定分页。AC：条件可 URL 分享，无重复/漏页。
- LM-302：题目详情、公式、图片、N 个小问。AC：桌面/手机可用，可复制表达式。
- LM-303：登录、进度个人空间、权限。AC：学生不能读取他人数据。
- LM-304：题单、收藏。AC：撤稿题不对外展示。

### EPIC E04：判题与学习（P0，S4–S6）
- LM-401：Submission/Evaluation 版本链与幂等。AC：同 key 重试不重复提交或计分。
- LM-402：选项/数值、分数/小数判题。AC：容差与单位测试通过。
- LM-403：符号表达式解析隔离与等价判断。AC：定义域反例/超时用例处理正确。
- LM-404：证明题“待复核”通道 + 审核页面。AC：不虚构已完成自动证明评分。
- LM-405：历史、错题/再练习、内容问题举报。AC：重判不覆盖原 evaluation。

### EPIC E05：多源导入（P0/P1，S5–S7）
- LM-501：导入 manifest、来源管理、文件签名校验（P0）。AC：错误 SHA 不进入队列。
- LM-502：CSV/JSONL 两个 adapter 规范化、原始存储（P0）。AC：一条失败不影响其他行。
- LM-503：source key/内容 hash 幂等 + 模糊重复候选（P0/P1）。AC：5 次导入不重复创建；不能自动误合并。
- LM-504：导入批次、重试、quarantine、审核归档（P0）。AC：错误码和每行状态可导出。
- LM-505：Rights expiry / conflict / takedown workflow（P0）。AC：到期内容即刻断公开访问。

### EPIC E06：上线与运维（P0，S1–S8）
- LM-601：单元/契约/集成/E2E 和数学黄金用例。AC：CI 绿灯阻断错误发布。
- LM-602：迁移、Docker Compose/开发环境、备份与恢复演练。AC：干净环境一键部署并还原数据。
- LM-603：性能/可用性/审计/告警。AC：目标压测与告警演练。
- LM-604：内容质量报告/运营 SOP。AC：抽检、复核、撤稿、重判有操作文档。

## 4. Backlog 分优先级

P0：E01 全部、E02 录入/审核/发布、E03 列表详情/基础账号、E04 可确定判题 + 人工待复核、E05 来源/授权/批次/幂等、E06 质量安全。

P1：批量内容编辑、数学表达式搜索、教师专题题单、详细知识点统计、重复候选排序增强、导入分级权限、审查队列效率。

P2：题目推荐、证明步骤 AI 辅助、OCR 辅助导入、Manim 自动分镜、视频渲染、学生数学实验。

## 5. 内容供给里程碑（建议）

W2：10 道原创/合法示例含极端情况；
W5：30 道手工完整录入（含代数、函数、几何、概率）；
W8：100～300 道经复核的试点题；
W14：两种不同格式题源成功接入（例如人工 JSONL + 合法合作方 CSV），达到相同内容契约；
W16：试点公开前完成 100% 来源和授权核验。数量目标只作为项目规划，可按实际教研能力调整。

## 6. 风险登记

| 风险 | 严重度 | 预防/应对 |
|---|---|---|
| 版权来源不明 | Critical | rights hold，先原创内容，不公开导入 |
| 数学答案错误/误判 | Critical | 人工审校+判题黄金样本，支持撤稿/重判 |
| schema 提前绑定上海 | High | curriculum release 与 source 分离 |
| 大量重复题导致体验差 | High | 来源映射、候选审核、规范身份 |
| OCR 错字/公式识别偏差 | High | 不经人工核验不发布 |
| 工程范围膨胀 | High | 先 P0 闭环，AI/Manim 放 Phase 2 |
| 题目版本影响历史成绩 | High | 不可变 Revision + Evaluation append-only |
| 题库扩张导致检索变慢 | Medium | 搜索读模型、索引、游标分页、压测 |

## 7. Definition of Ready / Done

Ready：明确用户故事、业务规则、P0/P1、API/字段、失败场景、版权/权限影响、AC 和测试样例。
Done：代码审查、迁移可回放、单元+契约+E2E、RBAC 检查、审计/监控、接口文档/示例更新、教研验证、QA 签收。发布相关特性额外要求不可变版本与权利 gate 覆盖。
