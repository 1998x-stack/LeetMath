# 02｜用户旅程、页面与交互详细规格

## 1. 信息架构

学生导航：题库 → 题单 → 最近练习/错题/收藏 → 我的。
内容管理员导航：题目 → 来源 → 导入任务 → 审核队列 → 质量问题 → 运营数据。
管理入口不暴露给普通学生，但后端仍必须逐请求鉴权。

## 2. 学生端关键用户故事

ST-01：作为学生，我要在 3 步内找到“高中/上海/导数”的中等难度题。筛选项：学段、地区、课程体系、知识点树、多选题型、难度范围、是否已做、是否有详细解析。已选条件可删除；URL 查询参数可分享。

ST-02：作为学生，我想知道一道大题有几问、每问分值和全题进度。详情显示标题/题号、统一题干、依次的小问、当前作答状态（未开始/草稿/已提交/待复核/完成），可小问导航；切问保留未提交草稿（本地持久化需有清晰隐私提示，服务端有登录时草稿可在后续版本考虑）。

ST-03：作为学生，我可以输入数学表达式，而不必完全照抄标准答案。答案框提供 LaTeX 预览、常用数学键盘和纯文本回退。按提交前检查格式，提交中禁用重复提交；网络失败保留内容与重试按钮；错误原因分“格式解析失败/无法判定/数学不等价”。

ST-04：作为学生，我希望知道哪个知识点欠缺。P0 展示按知识点汇总的正确/尝试次数（不宣称等价于真实掌握），P1 提供错题集合与再次练习。多小问通过各自标签归类。

ST-05：作为学生，我能举报题目错误。入口在每个小问，选择原因+说明，回执具有编号和状态。

## 3. CMS 内容编辑用户故事

ED-01：新建题目选择来源（原创、授权第三方、教材章节/试卷），填写原始题号和权利信息，保存草稿自动生成内部 UUID；第一次保存失败不会丢失输入。

ED-02：题目编辑器支持公共题干、N 个小问、插入图片/表格/公式、单问答案类型、得分点和答案解析；拖动排序时 part_key 保持稳定，不能因为视觉排序变化而改变历史 ID。

ED-03：送审前预检提供可操作结果：缺少标准答案、数学公式无法渲染、附件不存在、标题冲突、权利失效、答案定义域缺失、示例与判题器冲突。阻断项禁止送审；警告项可说明原因。

ED-04：Reviewer 在原始题与规范化稿的双栏对比界面检查数学正确性、答案类型、图片、课程/知识点、版权；可局部批注并驳回。Editor 不可批准自己创建/重大修改的题目（P0）。

ED-05：任何已发布题的修改都进入新 draft revision；只做展示层非语义修补也需要明确修订分类、审计和发布记录。

## 4. 页面状态约定

| 页面/组件 | Loading | Empty | Error | Success |
|---|---|---|---|---|
| 题库列表 | 骨架卡 | 推荐重置筛选 | 可重试并保留查询 | 件数+分页+最后更新 |
| 题目详情 | 占位题干 | 已下架/无权限 | 404/403/500 分离 | 版本号+来源+题目内容 |
| 交卷/提交 | 禁止二次提交 | 空答案有必填提示 | 422 输入、409 版本、503 判题不可用 | 正确/错误/待复核 |
| CMS 编辑 | 载入旧草稿 | 创建模板 | 字段定位+保留输入 | 保存版本和更新者 |
| 批量导入 | 步骤进度 | 无任务引导 | 逐条错误码下载 | 数量汇总+审核链接 |

## 5. 题目详情布局

Desktop：左侧题干与小问，右侧知识点/进度/笔记（可折叠）；移动端单列，问题导航为顶部滚动标签。每问固定区域：题目内容 → 答题组件 → 提交与反馈 → 解析（按权限与策略显示）。

来源/版权区：显示必要的作者/机构/年份/许可文本或链接；“上海高考真题”须有经核验原始官方年份、试卷类型和来源，不得根据相似度猜测。撤稿时显示提示，不回显受限制正文。

## 6. 无障碍与键盘

全局 Tab 可达、明显焦点、响应式布局、公式附近提供可复制的 LaTeX 或可读描述、图片必有 alt；交卷结果不仅靠颜色区分；误点击提交可以撤销未送达操作，但已完成判分的提交保留记录。组合输入法与数学编辑器不得冲突；移动网络中断时提示重试。

## 7. 边界与异常场景

- 内容在学生打开后被撤稿：提交时返回 409 CONTENT_RETRACTED；不得展示旧答案全文。
- 草稿被其他编辑者修改：乐观锁 revision_token 不匹配，提示冲突与差异，不能静默覆盖。
- 教师修改题目后学生重试：前端主动拉取新版本，旧作答留在原版本。
- 符号判题耗时过长：转入 pending_review 或 timeout，禁止将超时当错题。
- 来源元数据缺失：进入 quarantine，不允许公开发布。
- 无登录、错误角色、超范围素材访问：返回正确的 401/403，不泄露对象存在性和私有题目内容。
