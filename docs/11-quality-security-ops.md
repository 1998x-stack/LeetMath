# 11｜质量保证、安全、性能、内容版权和运维

## 1. 环境与交付

dev/staging/production 分离；staging 使用合成数据或经授权脱敏素材。推荐 FastAPI + PostgreSQL + Redis/任务队列 + S3 兼容对象存储 + 前端 Next.js；这是候选技术栈，不是已经实现。迁移由 Alembic 版本化；最小 Docker Compose 用于本地联调，生产须设置密钥、备份、网络隔离和访问边界。

## 2. 测试金字塔

- Schema：题目 JSON Schema、权利策略、来源映射、必填字段、错误示例。
- 领域单测：版本不可变性、Part 关联、rubric 汇总、内容 hash、source idempotence。
- 数学黄金样例：正确、错误、符号等价、定义域差异、单位/容差、超时、证明人工审核。
- 集成：Postgres + object store + queue + search/outbox；迁移前后记录可读。
- API 契约：OpenAPI 与客户端 DTO 同步；401/403/409/422/429/503。
- E2E：教师录入→双审核→发布→学生检索→逐问提交→复核/撤稿；跨设备响应。
- 灾备：备份恢复、删错草稿恢复、权利到期后权限变更、失败批次重试。
- 安全：越权 IDOR、XSS（Markdown/LaTeX/SVG）、上传恶意文件、SSRF（远程媒体导入）、重放、CSRF、CAS 资源耗尽。

## 3. 安全边界与学生隐私

- 后端 RBAC + scope，不能仅前端隐藏按钮；每次对象访问校验 ownership/tenant/visibility。
- 未成年人数据最小收集；保留期限、删除/导出、学校协作关系、第三方处理者均需法律/隐私审查。
- 用户数学答案和学习历史不放进公共日志/通用 analytics。脱敏日志贯穿 request_id、content_revision_id 和 grader_version。
- 原始 PDF/图片、私有题库、受限素材使用短效签名 URL；对象存储禁公网桶开放。
- 上传 MIME 检查、病毒扫描、大小限制、压缩炸弹防护；异步 OCR/媒体处理无网络/最小权限。
- 富文本强制净化、CSP、SVG 安全策略；展示公式不得执行 HTML/JS。
- CAS/用户表达式处理独立容器/进程，限制时间内存/CPU/对象数；拒绝直接 eval。
- 令牌/数据库凭据使用 secrets management，不纳入 Git；限制管理员访问审计日志。

## 4. 版权与来源风控

内容状态与权利状态为独立状态机。授权范围至少包含：显示(display)、复制(reproduce)、改编(adapt)、再分发(redistribute)、导出(export)、商业使用、地域、到期时间、署名要求。若一份题来自多个来源，公开展示版本必须满足所用文本/图/解答各自的授权条件，不能“合并后失去来源”。投诉渠道和 takedown SOP 必须在公开前准备。学生历史引用遵循必要的保留和删除策略，不能用版权/审计名义无限保存。

## 5. SLO / 容量假设（待压测确认）

| 指标 | 建议初期 SLO |
|---|---|
| 公开 GET API 可用性 | 月度 99.9%（不含计划维护，明确统计口径） |
| 题目详情 P95 | < 500ms，正常数据量/负载条件下 |
| 检索 P95 | < 800ms，100k 题试点压测 |
| 自动判题前台响应 | P95 < 2s 或返回 202 异步待完成 |
| 导入幂等 | 同 manifest 重跑新增重复源记录数 = 0 |
| 权利撤销 | 公开接口/缓存阻断 P95 < 60s（目标） |
| 备份恢复 | RPO 24h、RTO 4h（试点目标，按学校/合同调整） |

这些数值均是**建议的验收目标**，不是既有系统实测值。压测需记录硬件、并发、数据规模、访问分布与缓存命中率。

## 6. 监控与告警

服务：api latency, errors, db pool, queue lag, object store failures, search indexing lag, submission evaluation failures；
内容：发布前检查失败率、每源解析失败率、待审核龄、重复候选积压、授权即将到期、举报 P0 个数；
合规：越权拒绝、原始素材访问、异常导出峰值和 rights hold 生效时间。监控标签禁止放学生原始姓名/答案文本。

## 7. 恢复与回滚演练

每天定期备份 + 定期恢复验证；发布出错以“撤稿/回滚公开指针”而非物理删除历史版本；内容错误可重判并保留旧 Evaluation。导入任务支持暂停/继续/逐行重试；删除批次仅清理尚未发布的派生草稿，保留原始档案和审计。数据库迁移上线前全量备份和向后兼容演练。

## 8. 上线阻断门槛

1. 版权/授权无证据公开展示 = 0。
2. 数学错误或自动判题严重 false-positive 未修复 = 0。
3. IDOR、XSS、任意代码执行风险 = 0（已知未修复 P0）。
4. 版本修订破坏历史作答 = 0。
5. 无法重放/回滚导入或无法恢复备份 = 阻断。
6. 主要链路 P0 E2E 通过，运营 SOP 和紧急联系人已明确。
